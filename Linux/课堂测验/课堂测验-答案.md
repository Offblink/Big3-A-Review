### 选择题逐题解析（含干扰项）

> 题干与选项按 `课堂测验.docx` 转录；每题的四个选项都说明用途或错因。

**1. Linux 系统的主要设计思想源于哪个操作系统？ 答案 C（UNIX）**
- Linux 1991 年从内核起步，但"一切皆文件、单一根树、多用户/多任务、管道加小工具组合"这套设计直接继承 UNIX，POSIX 标准也来自 UNIX。
- A Windows：图形化商业系统，盘符分区、注册表，设计目标不同。
- B macOS：本身是 UNIX 认证系统（Darwin/XNU），算"同源"而非 Linux 的来源。
- D DOS：单任务、无多用户与权限模型，与 Linux 无关。

**2. 文件权限三部分：用户权限、组权限和______。 答案 C（其他权限）**
- 权限按身份分三档：u 所有者、g 同组、o 其他人。
- A 系统权限：不存在这个分类，权限只按身份划分。
- B 网络权限：没有这一类（网络访问由防火墙、SELinux 等控制）。
- D 管理员权限：root 是"用户身份"而不是第三类权限；root 属于 u 的范畴（且可绕过权限检查）。

**3. /home 目录的主要用途？ 答案 B（存储用户的个人文件）**
- 每个用户一个 `/home/<user>`，放文档、桌面、`~/.bashrc` 等个人配置。
- A 系统配置在 `/etc`；C 日志在 `/var/log`；D 设备文件在 `/dev`，内核模块在 `/lib/modules`。

**4. 哪个命令用于显示文件内容？ 答案 B（cat）**
- `cat file` 把内容写到标准输出，`cat -n` 带行号。
- A `rm` 删除；C `mkdir` 建目录；D `chmod` 改权限。
- 补充：长文件用 `less`/`more` 分页，看头尾用 `head`/`tail`。

**5. chmod 755 的含义？ 答案 B（所有者完全权限，组和其他用户只读 + 执行）**
- 755 = `rwx r-x r-x`：7=4+2+1、5=4+1。
- A 描述的是 666（`rw- rw- rw-`）。
- C "删除文件权限"：755 是设置权限；要移除某类权限得用符号法，如 `chmod -x file`，与 755 无关。
- D 描述的是 700（`rwx --- ---`）。
- 补充：目录的 `x` 位表示"可进入/可遍历"，所以目录常用 755。

**6. 哪个命令用于进入某个目录？ 答案 C（cd）**
- `cd` = change directory；`cd -` 回上一个目录，不带参数回家目录。
- A `ls` 列目录；B `pwd` 显示当前路径；D `mkdir` 建目录。

**7. Shell 中如何表示变量的值？ 答案 A（$）**
- `$var` / `${var}` 取变量值，`$(cmd)` 取命令输出。
- B `&` 放命令末尾表示后台执行。
- C `%` 在 `$(( ))` 里是取模，作业控制里 `%1` 是作业号。
- D `@` 只出现在 `$@`（全部参数）和数组 `arr[@]` 里，不是取值的通用前缀。

**8. 哪个符号表示输入重定向？ 答案 B（<）**
- `cmd < file` 把文件接到标准输入。
- A `>`：输出重定向（覆盖），`>>` 追加。
- C `|`：管道，前一个命令的 stdout 接到后一个的 stdin。
- D `&`：后台执行。

**9. 哪个命令可用于循环结构？ 答案 B（while），D（select）同样成立**
- `while 条件; do ...; done`，条件为真时反复执行。
- A `if`：分支，不循环；C `case`：多分支匹配，不循环。
- D `select`：bash 的菜单循环（`select x in a b; do ...; done`），也是循环结构，本题双答案。
- 补充：Shell 的循环还有 `for`、`until`。

**10. 哪个工具可以调试 C 程序？ 答案 C（gdb）**
- `gcc -g` 编译带调试信息，再 `gdb ./a.out`：`break`、`next`、`step`、`print`、`bt`。
- A `vim` 编辑器；B `gcc` 编译器；D `make` 按 Makefile 组织构建。

## 三、简答题（每题 10 分，共 30 分）

### 1. 简述 Linux 与 Windows 在文件目录结构上的主要区别

- Linux 是单一根树 `/`，一切皆文件，没有盘符概念；任何分区或设备都挂载到某个目录（`/mnt`、`/media`、`/home`）。
- **目录职责固定**：`/etc` 配置、`/bin` `/usr/bin` 可执行文件、`/var` 可变数据与日志、`/home` 用户目录、`/dev` 设备文件、`/proc` `/sys` 内核虚拟文件系统。
- Windows 是多盘符 `C:\ D:\`，每个盘独立成根，用 `\` 作分隔符；**配置分散在注册表**、`C:\Windows`、`Program Files`。
- Linux 路径大小写敏感，不靠扩展名判断文件类型（靠权限位与执行位）；Windows 路径大小写不敏感。

### 2. 绝对路径与相对路径的区别及使用场景

- 绝对路径：从 `/` 开始写全，如 `/home/tom/doc/a.txt`；与当前工作目录无关，任何位置都能用。
- 相对路径：相对当前工作目录（`pwd`），如 `./a.txt`、`../bin`、`docs/x.md`。
- 使用场景：脚本、服务、定时任务里用绝对路径（运行时 cwd 不可控）；交互操作、项目内跳转用相对路径（简短、整个项目搬移后仍可用）。例：`cd /etc` 是绝对跳转，`cd ../..` 是相对跳转。

### 3. 如何处理文件的权限问题（命令与示例）

- 三类身份：u 所有者、g 同组用户、o 其他用户；三类权限：r(4)、w(2)、x(1)。用 `ls -l` 查看，如 `-rwxr-xr-x`。
- 符号法：`chmod u+x file`、`chmod go-w file`、`chmod a+r file`。
- 数字法：`chmod 755 dir`（rwxr-xr-x）、`chmod 644 file`（rw-r--r--）、`chmod 600 ~/.ssh/id_rsa`。
- 递归与属主：`chmod -R 750 proj`、`chown user:group file`；新建文件的默认权限由 `umask 022` 控制。
- 权限不足时的排查顺序：`ls -l` 看目标文件 → 检查上级目录是否有 `x` 位 → 必要时 `sudo` 或调整属主，不要直接用 `chmod 777`。

## 四、编程题（共 35 分）

### 1. Shell 编程题（15 分）

```bash
#!/bin/bash
# 1) 打印当前目录下所有文件的列表
ls -l

# 2) 创建 backup 目录（-p 使重复运行不报错）
mkdir -p backup

# 3) 把所有 .txt 文件移动到 backup 目录
for f in *.txt; do
    [ -e "$f" ] || continue      # 无 .txt 时 glob 保持字面量，需跳过
    mv -- "$f" backup/
done
```

要点：
- `mkdir -p` 让脚本幂等，重复执行不报错。
- `[ -e "$f" ] || continue` 防止目录里没有 `.txt` 时把字面量 `*.txt` 移走。
- `mv --` 防止文件名以 `-` 开头被当成选项。

### 2. C 语言编程题（20 分）

本题按「从标准输入读取两个整数」理解，程序从 stdin 读入，结果打到 stdout。

```c
#include <stdio.h>

int main(void)
{
    long long a, b;

    if (scanf("%lld %lld", &a, &b) != 2) {
        fprintf(stderr, "读取失败：需要两个整数\n");
        return 1;
    }

    printf("%lld\n", a + b);

    return 0;
}
```

编译运行（Linux 下产物为 `sum`，MinGW/Windows 下为 `sum.exe`）：

```bash
gcc -Wall -O2 sum.c -o sum
echo "3 5" | ./sum     # 输出 8
./sum <<< "3 5"        # 同上，here-string 写法
```

要点：
- 用 `long long` + `%lld` 而非 `int`：Linux 上 `long` 是 64 位，但 Windows/MinGW 的 `long` 只有 32 位，`long long` 两边都对。
- `scanf` 返回值判断，输入不足两个数时报错退出，而不是拿未初始化的值算垃圾结果。
- 输入按空白分隔即可，空格或换行都行。
