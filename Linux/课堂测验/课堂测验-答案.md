## 三、简答题（每题 10 分，共 30 分）

### 1. 简述 Linux 与 Windows 在文件目录结构上的主要区别

- Linux 是单一根树 `/`，一切皆文件，没有盘符概念；任何分区或设备都挂载到某个目录（`/mnt`、`/media`、`/home`）。
- **目录职责固定**：`/etc` 配置、`/bin` `/usr/bin` 可执行文件、`/var` 可变数据与日志、`/home` 用户目录、`/dev` 设备文件、`/proc` `/sys` 内核虚拟文件系统。
- Windows 是多盘符 `C:\ D:\`，每个盘独立成根，用 `\` 作分隔符；**配置分散在注册表**、`C:\Windows`、`Program Files`。
- Linux 路径大小写敏感，不靠扩展名判断文件类型（靠权限位与执行位）；Windows 路径大小写不敏感。

### 2. 绝对路径与相对路径的区别及使用场景

- 绝对路径：从 `/` 开始写全，如 `/home/tom/doc/a.txt`；与当前工作目录无关，任何位置都能用。
- 相对路径：相对当前工作目录（`pwd`），如 `./a.txt`、`../bin`、`docs/x.md`。
- 使用场景：脚本、服务、定时任务里用绝对路径（运行时 cwd 不可控）；交互操作、项目内跳转用相对路径（简短、整个项目搬移后仍可用）。例：`cd /etc` 是绝对跳转，`cd ../..` 是相对跳转。

### 3. 如何处理文件的权限问题（命令与示例）

- 三类身份：u 所有者、g 同组用户、o 其他用户；三类权限：r(4)、w(2)、x(1)。用 `ls -l` 查看，如 `-rwxr-xr-x`。
- 符号法：`chmod u+x file`、`chmod go-w file`、`chmod a+r file`。
- 数字法：`chmod 755 dir`（rwxr-xr-x）、`chmod 644 file`（rw-r--r--）、`chmod 600 ~/.ssh/id_rsa`。
- 递归与属主：`chmod -R 750 proj`、`chown user:group file`；新建文件的默认权限由 `umask 022` 控制。
- 权限不足时的排查顺序：`ls -l` 看目标文件 → 检查上级目录是否有 `x` 位 → 必要时 `sudo` 或调整属主，不要直接用 `chmod 777`。

## 四、编程题（共 35 分）

### 1. Shell 编程题（15 分）

```bash
#!/bin/bash
# 1) 打印当前目录下所有文件的列表
ls -l

# 2) 创建 backup 目录（-p 使重复运行不报错）
mkdir -p backup

# 3) 把所有 .txt 文件移动到 backup 目录
for f in *.txt; do
    [ -e "$f" ] || continue      # 无 .txt 时 glob 保持字面量，需跳过
    mv -- "$f" backup/
done
```

要点：
- `mkdir -p` 让脚本幂等，重复执行不报错。
- `[ -e "$f" ] || continue` 防止目录里没有 `.txt` 时把字面量 `*.txt` 移走。
- `mv --` 防止文件名以 `-` 开头被当成选项。

### 2. C 语言编程题（20 分）

本题按「从标准输入读取两个整数」理解，程序从 stdin 读入，结果打到 stdout。

```c
#include <stdio.h>

int main(void)
{
    long long a, b;

    if (scanf("%lld %lld", &a, &b) != 2) {
        fprintf(stderr, "读取失败：需要两个整数\n");
        return 1;
    }

    printf("%lld\n", a + b);

    return 0;
}
```

编译运行（Linux 下产物为 `sum`，MinGW/Windows 下为 `sum.exe`）：

```bash
gcc -Wall -O2 sum.c -o sum
echo "3 5" | ./sum     # 输出 8
./sum <<< "3 5"        # 同上，here-string 写法
```

要点：
- 用 `long long` + `%lld` 而非 `int`：Linux 上 `long` 是 64 位，但 Windows/MinGW 的 `long` 只有 32 位，`long long` 两边都对。
- `scanf` 返回值判断，输入不足两个数时报错退出，而不是拿未初始化的值算垃圾结果。
- 输入按空白分隔即可，空格或换行都行。
