## 说明

- 资料为个人复习整理，不保证完整或准确，有问题欢迎提 Issue。
- 部分资料的 **Word 文档里附了我自己写的简化答案**（目前是 `Linux/课堂测验/` 的 Word 答卷）：只求能对付考试，能省则省，**不保证严谨**，愿意的话可以参考。日后这类简化答案会越来越多。
- **日后我会逐步更新**，补充新科目和修订内容，本仓库会持续完善。

## 使用

直接下载对应文件即可。Markdown 文件可用任意编辑器，或者 GitHub 网页查看；Word / PPT 文件下载后打开。

## 软广

嫌编辑器打开`.md`文件不方便？试试 [MDPad](https://github.com/Offblink/MDPad)（我做的嘻嘻😁），一个 Windows 上的 Markdown 编辑器：

- 双击 `.md` 直接开，Fluent 风格界面，深色/浅色都跟系统走；
- 实时预览，KaTeX 公式和 mermaid 流程图都能直接渲染；
- 一键导出 HTML，想打印成纸质版抄公式也行；
- Release 里就一个单文件 exe，下载双击即用，不装运行库、不弹广告、不联网。
