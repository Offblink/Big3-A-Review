> 对应 `2026-2027-1-计算机网络技术-期末复习.docx` 的「一、单项选择题（10 分）」——原卷实际 15 题，答案已标在题干括号里。
> 本文只补选项级解析（含干扰项）；判断题、术语辨析、设计题、计算题、分析题原卷已填，此处不重复。
> 标 **[⚠ 勘误]** 的题：卷面标注与题面/知识点冲突，按知识点给出应选答案；考试以老师口径为准。

## 逐题解析

**1. 广泛采用 CRC 的原因是 CRC 可以（B）检测出多位突发性差错**
- A 检测出一位差错：CRC 确实能检出全部单比特错，但奇偶校验也能，这不是"广泛采用"的理由。
- B 正确：r 位校验码能检出所有长度 ≤ r 的突发错误；更长突发错误的漏检率约为 $2^{-r}$，实现只需移位寄存器 + 异或。
- C 检测并纠正一位差错：CRC 只检错，不纠错；纠错要用海明码等。
- D 检测并纠正多位：更做不到。

**2. 可靠传输协议中的"可靠"是指（卷面 A）** **[⚠ 勘误/存疑]**
- A 使用面向连接的会话：TCP 面向连接，但"面向连接"描述的是通信前先建连接，本身不保证不丢、不重、按序——连接建立后照样可能丢包。
- B 使用"尽力而为"的传输：这是 IP 的语义，恰恰是"不可靠"。
- C 使用滑动窗口来维持可靠性：滑动窗口主要做流量控制、提高吞吐，不是可靠的定义。
- D 使用确认机制来维持可靠性：收到确认才认为送达，超时重传、序号去重——这才是"可靠"的核心。
- 结论：按"可靠 = 无差错、不丢失、不重复、按序到达"的定义，应选 **D**；卷面标 A，属口径差异（有的老师把"面向连接"当成可靠的前提），答题按老师答案，理解上记 D。

**3. 不需要为用户设置账号和口令的服务是（D）DNS**
- A Telnet：要登录账号才能进远端 shell。
- B FTP：要账号（匿名 FTP 也用 `anonymous` 这个公用账号）。
- C E-mail：收发要账号口令认证。
- D 正确：公共 DNS 解析器开放查询，不设账号（内网递归解析器可用 ACL 限制来源，但那是地址限制，不是账号）。

**4. SDN 控制层智能体的核心作用（B）**
- A 直接在交换机端口完成硬件线速转发：这是**数据层**（OpenFlow 交换机）的职责。
- B 正确：控制器生成全网流表、下发转发策略、同步底层设备状态，通过南向接口（OpenFlow 等）操作交换机。
- C 替代终端主机完成所有业务计算：越权，业务仍在主机上跑。
- D 仅负责 DNS 解析：DNS 是应用层服务，与控制层无关。

**5. 203.96.100.2/22 包含几个 C 类地址（D）4**
- /22 掩码 `255.255.252.0`，地址块 203.96.100.0–203.96.103.255，共 1024 个地址 = 4 个 /24（C 类）。
- 记法：C 类地址数 = $2^{24-\text{前缀长度}}$，/22 → $2^2=4$。
- A 1（那是 /24）、B 3（块大小总是 2 的幂）、C 2（那是 /23）。

**6. 212.12.38.0，掩码 255.255.255.128，各子网可用主机地址总数（卷面 C）** **[⚠ 勘误]**
- /25 每个子网 128 个地址，去掉网络号与广播地址 = **126 个可用主机地址**，应选 **D**。
- A 254：/24 的可用数；B 252：不是本题任何口径的结果；C 128：是**地址总数**，不是"可用主机"数。
- 结论：卷面 C 疑为把"地址数"当成"可用主机数"，按定义应为 D（126）。

**7. 下列有关"域名"的叙述中不正确的是（B）** **[⚠ 题目瑕疵]**
- B "域名是字符形式的 IP 地址"：不准确——域名与 IP 是两套命名空间，靠 DNS 映射；一个域名可对应多个 IP，一个 IP 也可对应多个域名。
- A "域名反映计算机所在的物理地点"：按教材域名是**逻辑概念，与地理位置无关**（`cn` 只表示注册/管理归属），这句话本身也错。
- C 层次结构命名（根、`com`、`example`）正确；D 同一时刻主机的完全限定域名唯一，基本正确。
- 结论：A、B 都不严谨，单选题按卷面取 **B**（B 错得更直接）。

**8. 主机 B 对 `SYN=1, seq=1220` 的正确应答（卷面 C）** **[⚠ 勘误]**
- 正确的 SYN-ACK 必须同时满足：`SYN=1`、`ACK=1`、`ack=1221`（对方序号 +1）、`seq` = B 自己选的初始序号（任意）。
- A `SYN=1, ACK=1, seq=1221, ack=1221`：标志位与确认号都对，`seq=1221` 只是 B 恰好也选了 1221 作 ISN，**合法** → 应选 **A**。
- B `SYN=1, ACK=1, seq=1220, ack=1220`：`ack` 没有 +1，错。
- C `SYN=0, ACK=0, seq=1221, ack=11221`、D `SYN=0, ACK=0, ...`：没有 SYN/ACK 标志，根本不是 SYN-ACK 报文段（C 的 `ack=11221` 也明显异常，疑原卷录入错误）。
- 结论：卷面 C 应为 **A**。

**9. TELNET 的端口号（A）23**
- B 70：Gopher；C 80：HTTP；D 110：POP3。
- 补充：FTP 21/20、SSH 22、SMTP 25、DNS 53、HTTPS 443、POP3S 995。

**10. 快速以太网冲突检测时间 = 网络最大传播时延的（A）2 倍**
- CSMA/CD 要求发送方在最远往返时间内能检测到冲突，争用期（时隙）= **2τ**，τ 为单程最大传播时延。
- B 1、C 4、D 6 都无依据。
- 补充：10 Mbit/s 以太网争用期 51.2 μs（512 bit 时间）；快速以太网保持 512 bit 时隙，把最大距离压到 100 m。

**11. 下面是 B 类主机地址的是（A）165.4.5.6**
- B 类首字节 128–191：165 落在区间内 ✓。
- B 123.0.0.1：A 类（1–126）。
- C 217.0.0.0：C 类（192–223），且主机号全 0 是网络地址，不能作主机地址。
- D 123.255.255.255：A 类广播地址。
- 补充：127 段回环，224–239 组播，240– 保留。

**12. 同一信道同一时刻能双向传送的通信方式（C）全双工**
- A 单工：只能固定一个方向（广播）。
- B 半双工：双向但不能同时（对讲机）。
- C 正确：双向同时（电话、全双工以太网）。
- D "上述三种均不是"排除。

**13. 要经过建立连接、数据传输、释放连接的方式（B）虚电路**
- A 数据报：无连接，每个分组独立选路。
- B 正确：先建逻辑通路（虚电路），再按序传输，最后释放。
- C 分组交换：是**总称**，数据报与虚电路都是它的实现。
- D 报文交换：整个报文存储转发，没有建立/释放连接的过程。

**14. C 类地址分 8 个子网，掩码应为（C）255.255.255.224**
- 8 = $2^3$，借 3 位主机位 → /27 → 末字节 224。
- A /32 不能这样用作子网掩码；B /24 等于不划子网；D /26 只有 4 个子网。
- 注意：旧教材"子网号不能全 0/全 1"的口径下要借 4 位（240）；现代设备支持全 0/全 1，标准答案取 224。

**15. 两台主机直接交换 IP 分组，要求具有相同的（D）子网号**
- "直接交换"= 不经过路由器，说明在同一广播域/子网，靠 ARP 取 MAC 后直接交付。
- A 相同 IP 地址：地址冲突，不成立。
- B 相同主机号：不同子网里主机号相同没有意义。
- C 相同物理地址：不可能（同一链路上 MAC 唯一）。
- D 正确：同一子网号 → 同一网段。
